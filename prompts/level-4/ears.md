1. WHEN a user opens a folder, IF it contains compatible audio or video files, THEN the system shall display an integrated mini-player allowing playback without leaving the file browser.

2. WHILE an audio or video file is playing, THE SYSTEM SHALL display playback controls including play/pause, seek, volume, and playback duration, IF the selected media supports these controls.

3. WHILE the user navigates between folders, IF the selected media is no longer available or cannot be played, THEN the system shall stop playback, reset the player state, and display an explicit error message when playback fails.
